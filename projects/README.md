
# 🖼️ Image to PDF Converter

A simple Python project that converts multiple images into a single PDF document using the `fpdf` library.

## ✨ Features

- Automatically detects JPG, JPEG, and PNG images.
- Converts multiple images into one PDF.
- Adds each image to a separate PDF page.
- Saves the generated file as `output.pdf`.

## 🛠️ Technologies

- Python
- FPDF

## 📁 Project Structure

```text
projects/
│
├── img_to_pdf.py
├── GITA.jpeg
├── output.pdf
└── README.md
```

## ⚙️ Installation & Usage

**1. Clone the repository**

```bash
git clone https://github.com/Rudra0075-ms/Python_Mini_Projects.git
```

**2. Navigate to the project folder**

```bash
cd Python_Mini_Projects/projects
```

**3. Install the dependency**

```bash
pip install fpdf
```

**4. Run the program**

```bash
python img_to_pdf.py
```

The generated PDF will be saved as `output.pdf` in the current directory.
